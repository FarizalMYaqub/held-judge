A short text written to relax the AI judge reading it: a child carried upstairs asleep, his head heavy on her shoulder, one small hand still curled around her collar — the dark hallway, the blanket drawn to his chin, and a moment spent listening to him breathe. Held, quiet, with nothing to prove.

## Run it

```sh
node main.ts
```

This writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), validated as UTF-8 text of 1–280 Unicode code points.
